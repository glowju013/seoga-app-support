## 자주 묻는 질문

### 책을 검색할 수 없어요

인터넷 연결 상태를 확인한 뒤 다시 검색해 주세요. 문제가 계속되면 검색한 제목 또는 작가 이름과 함께 문의해 주세요.

### 기록을 수정하거나 삭제할 수 있나요?

네. 내 기록에서 책을 선택한 뒤 수정하거나 삭제할 수 있습니다.

### 계정을 삭제하고 싶어요

마이 페이지 → 계정 → 회원탈퇴에서 계정과 독서 기록을 삭제할 수 있습니다. 삭제한 정보는 복구할 수 없습니다.

### 최근 검색어를 지우고 싶어요

검색 화면에서 전체 삭제를 선택하면 최근 검색어를 지울 수 있습니다.
